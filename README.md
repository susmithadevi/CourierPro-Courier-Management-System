# CourierPro – Courier Management System

CourierPro is a web-based courier management system developed using HTML, CSS and JavaScript.

## Features

- Dashboard
- Booking Management
- Shipment Tracking
- Delivery Personnel Management
- Route Management
- Billing & Invoicing
- Customer Management
- Reports
- Login System
- Search and Filter
- Dark Mode
- Local Storage
- CSV Export
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
